# Interactive Dashboard: การวิเคราะห์ความต้องการให้รัฐบาลช่วยเหลือของหมู่บ้าน/ชุมชนไทย ปี 2566–2567

Interactive Data Dashboard พัฒนาด้วย **Python, Streamlit, Pandas และ Plotly** เพื่อวิเคราะห์ความต้องการให้รัฐบาลช่วยเหลือ 3 อันดับแรกของหมู่บ้าน/ชุมชนไทย แยกตามจังหวัด ประจำปี พ.ศ. 2566 และ 2567 ร่วมกับตัวชี้วัดเสริมด้านเศรษฐกิจ การมีงานทำ และผลผลิตการเกษตร

---

## 📌 วัตถุประสงค์โครงการ

1. **ระบุประเด็นปัญหาสำคัญ:** วิเคราะห์ว่ากลุ่มปัญหาและความต้องการใดปรากฏใน 3 อันดับแรกของหมู่บ้าน/ชุมชนไทยมากที่สุด และกระจายตัวอยู่ในภูมิภาคหรือจังหวัดใด
2. **วิเคราะห์บริบทเชิงพื้นที่:** เปรียบเทียบความแตกต่างระหว่างจังหวัดที่รายงานปัญหากับตัวชี้วัดเสริมจริง ได้แก่ ค่าใช้จ่ายครัวเรือนเฉลี่ยต่อเดือน อัตราการว่างงาน และผลผลิตข้าวนาปีต่อไร่
3. **วิเคราะห์การเปลี่ยนแปลงระหว่างปี:** สำรวจการเปลี่ยนแปลงระหว่างปี 2566 และ 2567 ภายใต้ข้อจำกัดของนิยามข้อมูล
4. **นำเสนอด้วย Interactive Visualizations:** แดชบอร์ด 4 แท็บที่เชื่อมโยงฟิลเตอร์และข้อมูลเข้าด้วยกัน พร้อมระบบแสดงผลแผนที่ GeoJSON 77 จังหวัดจริง

## 📊 โครงสร้างแดชบอร์ดทั้ง 4 แท็บ

- **Tab 1: ภาพรวมความต้องการให้รัฐบาลช่วยเหลือ**
  - KPI Cards: จำนวนจังหวัด, กลุ่มปัญหา, รายการความต้องการ, ปัญหาที่พบบ่อยสุด
  - Treemap: การกระจายตัวของจำนวนจังหวัดตาม 6 กลุ่มปัญหา
  - แผนที่ Choropleth: จังหวัดที่รายงานกลุ่มปัญหา/ปัญหาย่อย
  - Bar Charts: การจัดอันดับกลุ่มปัญหา และการเปรียบเทียบปี 2566 vs 2567
  - ตารางข้อมูลเจาะลึก 3 อันดับแรกของแต่ละจังหวัด

- **Tab 2: เศรษฐกิจและการเงิน**
  - KPI Cards & Bar Chart: เปรียบเทียบจำนวนจังหวัดรายงานปัญหาเศรษฐกิจ 2566 vs 2567
  - แผนที่ Choropleth: ค่าใช้จ่ายครัวเรือนเฉลี่ยรายจังหวัด ปี 2567 (บาท/เดือน)
  - Box Plot with Jitter: การกระจายค่าใช้จ่ายครัวเรือนระหว่างกลุ่มที่รายงานและไม่รายงาน
  - Bar Chart: ค่าใช้จ่ายเฉลี่ยสองกลุ่มจังหวัด พร้อมระบุ $n$ จังหวัด
  - ตารางเจาะลึกข้อมูลเศรษฐกิจรายจังหวัด

- **Tab 3: อาชีพและการจ้างงาน**
  - KPI Cards & Bar Chart: เปรียบเทียบจำนวนจังหวัดรายงานปัญหาอาชีพ 2566 vs 2567
  - แผนที่ Choropleth: อัตราการว่างงานรายจังหวัด (%) ปี 2566 และ 2567
  - Box Plot: การกระจายอัตราการว่างงานระหว่างสองกลุ่มจังหวัด
  - Grouped Bar Chart: อัตราว่างงานเฉลี่ยเปรียบเทียบสองกลุ่มรายปี
  - Dumbbell Chart: การเปลี่ยนแปลงอัตราการว่างงานรายจังหวัด (จุดเปอร์เซ็นต์)
  - ตารางเจาะลึกข้อมูลอาชีพและการว่างงานรายจังหวัด

- **Tab 4: เกษตรกรรมและที่ดิน**
  - KPI Cards & Bar Chart: เปรียบเทียบจำนวนจังหวัดรายงานปัญหาเกษตร 2566 vs 2567
  - แผนที่ Choropleth: ผลผลิตข้าวนาปีต่อเนื้อที่เก็บเกี่ยว ปี 2567 (กก./ไร่)
  - Box Plot with Jitter: การกระจายผลผลิตข้าวนาปีระหว่างสองกลุ่มจังหวัด
  - Bar Chart: ผลผลิตข้าวเฉลี่ยสองกลุ่มจังหวัด พร้อมระบุ $n$ จังหวัด
  - ตารางเจาะลึกข้อมูลเกษตรและที่ดินรายจังหวัด

## ⚙️ วิธีติดตั้งและเรียกใช้งาน (Installation & Running)

### 1. ความต้องการของระบบ (Prerequisites)
- Python 3.10 ขึ้นไป
- การเชื่อมต่ออินเทอร์เน็ต (สำหรับการแสดงผล Map Tiles หากจำเป็น หรือใช้ GeoJSON ออฟไลน์ที่ติดตั้งไว้)

### 2. ติดตั้ง Dependencies
เปิด Terminal / PowerShell ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:
```bash
pip install -r requirements.txt
```

### 3. รัน Streamlit Dashboard
```bash
streamlit run app.py
```
เมื่อรันคำสั่งแล้ว เบราว์เซอร์จะเปิดแดชบอร์ดที่ `http://localhost:8501` โดยอัตโนมัติ

## ⚠️ ข้อควรระวังและข้อจำกัดทางสถิติ (Methodology & Caveats)

1. **ค่า `Per_vill`:** คือร้อยละของหมู่บ้าน/ชุมชนในจังหวัดนั้นที่รายงานความต้องการรายการดังกล่าว ไม่ใช่ร้อยละของประชากร และ **ห้ามนำร้อยละของปัญหาต่างประเภทมารวมกันเป็น 100%**
2. **การรายงานปัญหา:** หมายถึงการติด 1 ใน 3 อันดับความต้องการแรกที่ได้รับการสำรวจ จังหวัดที่ไม่ได้รายงานอาจยังมีปัญหานั้นอยู่แต่ไม่ติด 3 อันดับแรก
3. **การวิเคราะห์เชิงพรรณนา:** การเปรียบเทียบความแตกต่างระหว่างกลุ่มไม่ได้สะท้อนความสัมพันธ์เชิงเหตุและผล (No Causal Inference)
4. **ความครอบคลุมของปี:** ข้อมูลค่าใช้จ่ายครัวเรือนและผลผลิตข้าวนาปีมีเฉพาะปี 2567 ระบบจะไม่นำค่าปี 2567 ไปแทนค่าปี 2566 โดยเด็ดขาด
5. **กรณีอันดับเสมอ (Ties):** ในปี 2567 จังหวัดระนองและหนองบัวลำภูมีรายงาน 4 รายการเนื่องจากคะแนนเท่ากัน ระบบคงรายการไว้ครบถ้วนโดยไม่ตัดทิ้ง
